# تصميم شبكة متكاملة - Cisco Packet Tracer

## نظرة عامة
هذا المشروع يوضح تصميم شبكة عملية تم إعدادها وتكوينها باستخدام برنامج Cisco Packet Tracer، وهو يبرز مهارات ربط الشبكات وإعداد أجهزة التوجيه والمحولات (Routers & Switches).

## مخطط الشبكة (Topology)
![Network Topology](Screenshot%202026-08-16%20000104.png)
**1. تقنيات التبديل (Switching & Layer 2):**
* تقسيم الشبكة منطقياً (VLANs) وإدارة مزامنتها عبر بروتوكول (VTP).
* تكوين الروابط الناقلة (Trunking) لتمرير البيانات بين المحولات.
* دمج الروابط لزيادة سعة النطاق الترددي وتوفير التكرار باستخدام (EtherChannel).

**2. تقنيات التوجيه (Routing & Layer 3):**
* إعداد وتوزيع عناوين الشبكة (IP Addressing).
* التوجيه الديناميكي المتقدم باستخدام بروتوكول (OSPF).
* إعداد مسارات التوجيه الثابتة (IP Static Routing).
* تطبيق خاصية تلخيص المسارات (Route Summarization) لرفع كفاءة أداء الموجهات.
* توفير التوافرية العالية واستمرارية العمل باستخدام بروتوكولات الاستعداد (Standby / HSRP).

**3. خدمات الشبكة والتقنيات اللاسلكية (Network Services & Wireless):**
* إعداد خوادم الشبكة الأساسية: خادم الويب (HTTP)، وخادم الأسماء (DNS).
* التوزيع التلقائي لعناوين الأجهزة عبر إعداد خوادم (DHCP).
* ترجمة عناوين الشبكة (NAT / PAT) لتمكين الاتصال الخارجي.
* بناء وإدارة الشبكات اللاسلكية باستخدام وحدات التحكم (WLC) ونقاط الوصول (Access Points).
* تفعيل خدمات نقل الصوت عبر الشبكة (VoIP) وإعداد هواتف الـ IP.

**4. الأمان والإدارة (Security & Management):**
* تطبيق سياسات الأمان وتصفية البيانات باستخدام قوائم التحكم بالوصول (ACL).
* إنشاء اتصالات آمنة بين أجزاء الشبكة باستخدام (VPN).
* إعداد وتأمين منافذ الإدارة عن بُعد (VTY) للمحولات (Switches) والموجهات (Routers).
